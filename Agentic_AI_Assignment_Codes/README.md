# Agentic AI Systems — Assignment Solutions

This folder contains 28 independent Python programs: two assignment solutions for each of the 14 labs in the uploaded lab guide.

## Naming
- `Lab01_Assignment1A_...py` = Lab 1, Assignment 1
- `Lab01_Assignment1B_...py` = Lab 1, Assignment 2
- Likewise through Lab 14.

## Run
Use Python 3.10+ (no third-party packages required):
```bash
python Lab01_Assignment1A_Two_Rounds_Feedback.py
```
Run each file from this folder. Every program includes a demonstration under `if __name__ == "__main__":`.

## Important
- These are assignment-specific implementations, not copies of the guide's reference programs.
- The programs use local mock data and rule-based logic, matching the guide's offline/no-API approach.
- Lab 11 Assignment 2 intentionally contains a bug so the independent test can demonstrate catching it.
- Lab 12 Assignment 2 demonstrates the sixth proposal being blocked until re-evaluation.
- Review the output and adjust sample data/names if your instructor expects a different scenario.
